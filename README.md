# anime-scene-search

Модуль поиска аниме и манги по скриншоту. Подключается к основному приложению.

## Модули

imagesearch-api - контракты, зависит только от корутин.
imagesearch-core - идентификация сцены через trace.moe и SauceNAO, кэш, ретраи.
imagesearch-resolver - сопоставление тайтла с источниками приложения.

Идентификация не знает про парсеры, резолвер не знает про сеть.

## Что реализует приложение

FrameDecoder через Bitmap, ContentSource и SourceRegistry как адаптеры к парсерам,
ресайз скриншота до 640x360 JPEG перед отправкой.

## Проверка

sh check.sh - статический аудит без компиляции. Сборка идет в GitHub Actions.
