# Слой перевода: почему он отключён от сборки

## Что сделано

Модули `:translate:{core,mt,ocr,onnx,render}` и `:core:database` больше
не входят в граф зависимостей APK. Из всего слоя подключён только
`:translate:api` — это чистые типы: `TranslationMode`, `TextBlock`,
`BlockKind` и интерфейсы. Нативного кода в нём нет.

## Почему

Слой перевода **не инстанцируется**: `TranslationOrchestrator` нигде не
создаётся, ONNX-сессия не открывается, ML Kit не вызывается. При этом в
установочный пакет попадали:

```
lib/*/libtranslate_jni.so   16.4 МБ   (ML Kit translate)
lib/*/libonnxruntime.so     16.3 МБ   (ONNX Runtime)
```

плюс их вклад в dex. Пользователь скачивал 33 МБ нативного кода, который
не исполнялся ни разу.

Отдельно: ONNX-модели (`comic-text-detector.onnx`, `lama_inpaint_int8.onnx`)
в репозиторий никогда не клались, то есть даже при инстанцировании слой
не заработал бы — рантайм грузился бы без весов.

## Результат

| | до | после |
|---|---|---|
| APK со всеми ABI | 186 МБ | — |
| APK на устройство (arm64) | 62 МБ | **14 МБ** |

## Как включать обратно

Не возвращать строки зависимостей в `:feature:reader` — это вернёт и вес.
Правильный путь, когда перевод действительно понадобится:

1. **Доставка по требованию.** Вынести `:translate:*` и модели в
   Play Feature Delivery модуль (`on-demand`), чтобы они скачивались
   при первом включении перевода в настройках тайтла, а не при установке.
2. **Проверка доступности в рантайме.** Точка входа — `ReaderViewModel`:
   сейчас `translationMode` живёт в состоянии и доезжает до вьюхи, но
   текстовый слой не рисуется. Там же должна появиться проверка
   «модуль загружен?» с деградацией на `ORIGINAL`.
3. **Модели.** Класть не в `assets` модуля, а качать отдельно:
   `OnnxSessionFactory.materializeAsset` уже умеет работать с файлом в
   `filesDir`, ему нужен только источник.
4. `:core:database` вернуть вместе с `:translate:core` — Room-конвертеры
   нужны только кешу переводов.

Контракт `MangaPageSource` и `ReaderEvent.TranslationReady` при этом не
меняются: читалка уже умеет жить и с переводом, и без него.
