# Дизайн-кит Takami

Исходные макеты, присланные ilyuzor. Лежат в репозитории намеренно:
до этого они существовали только вложениями в чате, и агент, делавший
карточки, не смог их получить — сверять было не с чем, макет
восстанавливали по косвенным признакам.

`kit/*.jsx` — эталонная вёрстка экранов и компонентов. Это React, а не
то, что мы собираем: значение имеют структура, состояния и токены, а не
код. `kit-*.css` и `colors_and_type.css` — цвета, типографика, радиусы;
их андроидное отражение живёт в `core:design/Tokens.kt`.

Соответствие экранов:

| Макет | Что в приложении |
|---|---|
| `Home.jsx` | главная, рельсы, новости |
| `Library.jsx` | библиотека, сегменты манга / аниме / ранобэ |
| `Title.jsx` | карточка тайтла и экран тайтла |
| `Character.jsx` | карточки персонажей |
| `Reader.jsx` | читалка манги |
| `Player.jsx` | плеер |
| `Swipes.jsx` | подбор свайпами |
| `Search.jsx`, `AdvancedSearch.jsx` | поиск и фильтры |
| `Settings.jsx`, `Sources.jsx`, `Proxy.jsx` | настройки и источники |
| `Calendar.jsx` | календарь |
| `AiIndicator.jsx` | индикатор автопарсера |
| `Onboarding.jsx` | онбординг |

Расхождение с макетом — повод спросить, а не решить молча: часть
макетов описывает то, чего в приложении ещё нет.
