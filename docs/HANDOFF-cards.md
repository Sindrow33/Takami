# Карточки тайтлов и персонажей

Модуль `:feature:cards`. Только компоненты и экран — источник данных
готовит Инженер-2, модуль о нём не знает.

## Что подключить

```kotlin
// зависимость в app/build.gradle.kts (твой файл)
implementation(project(":feature:cards"))
```

Компоненты:

```kotlin
val loader = remember { ImageLoader(File(context.cacheDir, "card-images")) }

TitleCard(data, loader = loader, onClick = { ... })      // вертикальная, 2:3
TitleRowCard(data, loader = loader, onClick = { ... })   // широкая, для списка
TitleGrid(titles, loader = loader, onOpen = { ... })     // адаптивная сетка
TitleRail("Продолжить", titles, loader = loader)         // ряд на главной
CharacterCard(character, loader = loader)
CharacterRail(characters, loader = loader)
TitleDetailsScreen(data, description = ..., characters = ..., loader = loader)
```

Обязательных параметров, кроме данных, нет: `loader = null` рисует
плейсхолдеры, что удобно для превью.

## Модель

`TitleCardData` и `CharacterCardData` в `CardModels.kt`. Три решения по форме,
о которых договаривался с Инженером-2:

- `rating` — **готовая строка**, не число: иначе формат «8.4» против «8,4»
  решается в двух местах по-разному и расходится.
- `coverUrl` — **nullable, без заглушечного URL**: карточка сама рисует
  достойный плейсхолдер, а фиктивная ссылка даёт сломанную картинку.
- `id` — **строка с префиксом источника** (`manga:`, `anime:`, `web:`): иначе
  локальный и сетевой тайтл с одинаковым номером схлопываются в один. Уже
  ловил это в свайпах.

## Карточка без обложки

Обложки у разобранных тайтлов часто нет — это обычное состояние, не сбой.
Плейсхолдер: инициалы на градиенте, цвет **устойчив по идентификатору**
(`placeholderIndex` под тестами), поэтому один и тот же тайтл всегда одного
цвета и список не «мигает» при перерисовке. Плоскую заливку не использую: рядом с
настоящими обложками она читается как «картинка не загрузилась», градиент —
как оформление.

## Персонажи: данных нет, и это видно

Источника по персонажам в проекте нет вообще — ни автопарсер, ни локальные
файлы их не отдают. Моков я не делал намеренно: `CharacterRail` при пустом
списке показывает честное состояние с объяснением, почему пусто. Компонент и
экран готовы, включатся, как только источник начнёт отдавать данные.

## Мелочи, которые видно только на устройстве

- Обложка **пропорцией 2:3**, а не фиксированной высотой: обложки приходят
  разных размеров, при фиксированной высоте сетка расползается по вертикали.
- Портрет персонажа **3:4**: персонажей рисуют по грудь, квадрат режет лицо.
- Бейдж непрочитанного — **по содержимому, с формой «99+»**: в жёстком круге
  двузначное число прижимается к краю (ту же ошибку уже ловили на календаре).
- Колонки сетки заданы **минимальной шириной**, а не числом: три карточки на
  узком экране — нечитаемые полоски, две на планшете — половина пустого экрана.
- Пустой `TitleRail` не рисуется совсем: заголовок подборки без содержимого
  выглядит как не загрузившаяся секция.
- Под именем персонажа не больше одной строки на поле: две превращают ряд
  карточек в неровную гребёнку.

## Загрузчик картинок

`ImageLoader` — копия загрузчика из `:feature:swipes`, осознанно, а не общий
модуль: выносить сотню строк в отдельный `:core:image` ради двух потребителей
дороже, чем держать две копии. Появится третий потребитель — вынести.
Без Coil/Glide: библиотека изображений это ещё мегабайты в APK, а вес до сих
пор блокер релиза.

## Замена карточки на главной (для `:app`)

Данные для главной уже собирает `LibraryFeed` (PR #33). Поля совпадают
один в один, кроме имени типа: в `:app` это `ContentType`, в модуле —
`ContentKind`. Модуль не зависит от `:app` намеренно (обратная зависимость
замкнула бы граф), поэтому маппинг живёт на стороне `:app`:

```kotlin
private fun LibraryFeed.TitleCardData.toCard() = dev.takami.cards.TitleCardData(
    id = id,
    title = title,
    kind = when (kind) {
        ContentType.Anime -> ContentKind.Anime
        ContentType.Manga -> ContentKind.Manga
        ContentType.Novel -> ContentKind.Novel
    },
    coverUrl = coverUrl,
    subtitle = subtitle,
    rating = rating,
    badgeCount = badgeCount,
    progress = progress,
)
```

`when` без `else`: добавится четвёртый тип контента — компилятор укажет
на это место, а не покажет его как аниме.
