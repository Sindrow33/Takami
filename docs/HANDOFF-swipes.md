# Свайпы на реальных данных

## Что подключить в `MainActivity.kt` (одна замена)

```kotlin
// было: Tab.Swipes -> SwipesScreen()
Tab.Swipes -> SwipesScreen(
    source = swipeSource,
    decisions = swipeDecisions,
)
```

и рядом с остальными `remember` в `MainShell`:

```kotlin
val swipeSource = remember { TakamiSwipeSource(context) }
val swipeDecisions = remember { SwipeDecisions(context) }
```

Импорты: `dev.takami.app.swipes.SwipeDecisions`,
`dev.takami.app.swipes.TakamiSwipeSource`.

Больше в твоих файлах ничего не нужно: `app/build.gradle.kts` я не трогал
намеренно (см. ниже про формат хранения).

## Устройство

Модуль свайпов не знает, откуда берутся данные — он объявляет два интерфейса
(`SwipeSource`, `SwipeDecisionStore`), а реализации живут в `:app`, потому что
там и библиотека, и автопарсер. Иначе `:feature:swipes` пришлось бы завязать на
приложение, а зависимость идёт в обратную сторону.

Источники карточек:
- манга и аниме из локальной библиотеки (та же выбранная папка);
- тайтлы, снятые автопарсером с разобранных сайтов — с обложками.

## Что было разорвано в цепочке

Разбор сайта **выбрасывал разобранный каталог**. `SourceProber` печатал
«Каталог: 40 тайтлов» и терял их: результат нигде не сохранялся. То есть
свайпы не могли получить данные вообще, сколько бы сайтов ни разобрали.
Теперь `ParsedPayload.Listing` уходит в `DiscoveredTitles`, и в отчёте о
разборе появляется строка «Тайтлы добавлены в подбор свайпами».

Это тот же класс дефекта, что пять предыдущих: код работает, результат никем
не используется.

## Решения

- **«Мимо» не возвращается.** Решения хранятся в `SwipeDecisions`
  (SharedPreferences) и переживают перезапуск; колода собирается как
  `filterUndecided(все, решённые)`. Без этого подбор превращается в карусель
  одного и того же.
- **Пустое состояние — не ошибка.** Пока папка не выбрана и сайт не разобран,
  подбирать нечего. Экран говорит, что именно сделать, а не «список пуст».
- **«Пройти заново» очищает решения**, иначе после очистки колода собирается
  снова пустой.
- **Решение записывается после анимации, но до следующего свайпа** — иначе
  быстрая серия свайпов теряет часть записей.
- **Обложки — своя загрузка, без Coil/Glide.** Библиотека изображений это
  ещё несколько мегабайт в APK, а вес уже был блокером релиза. Нужно ровно
  одно: показать картинку в карточке. Кеш двухуровневый (память + диск с
  вытеснением по LRU), декод с прореживанием — полный битмап 1200px на каждую
  карточку это десятки мегабайт и рывок анимации.
- **Формат `DiscoveredTitles` — построчный, не JSON.** Плагин сериализации
  потребовал бы правки `app/build.gradle.kts`, а это файл Инженера.
  Разделитель — табуляция: в названии тайтла и в URL её не бывает.

## Что осталось половинчатым, и честно

`like()` сохраняет отметку в `LikedTitles`, но **не добавляет тайтл в
библиотеку**: библиотека читает файлы с диска, своей базы у неё нет, и
записать в неё сетевой тайтл сейчас некуда. Отметки сохраняются, чтобы при
появлении базы отложенное не пропало. Полноценное «нравится → библиотека»
делается вместе с базой библиотеки — это не моя зона.
