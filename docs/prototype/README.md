# Takami — UI-прототип

HTML/CSS/JS без бэкенда. Данные — `data.js`, состояние — localStorage.
Тема Aurora адаптирована из Tadami (Apache-2.0), см. NOTICE в корне.

Запуск: `busybox httpd -p 8080 -h .` → http://127.0.0.1:8080/home.html
Карта экранов: `hub.html`

Ключи localStorage: urd (прочитанное), udl/dlq (загрузки), srcHealth/srcPin
(источники), progNum (прогресс), lastRead, hist, acct/sess, sq (поиск).
